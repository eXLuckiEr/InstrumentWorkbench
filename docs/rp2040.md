# Плагин «IWP RP2040 board» (`plugins/device/rp2040`)

Шаблон плагина для приборов на прошивочной базе [IWP-RP2040-base](https://github.com/eXLuckiEr/IWP-RP2040-base):
SCPI поверх USB-CDC. Делает только то, что умеет сама база, и не знает ничего о конкретном приборе.
От него удобно отталкиваться: скопировать папку, переименовать (см. `new-device-plugin.md`) и добавить свои команды.

## Что показывает

| Данные | Команда прошивки |
|---|---|
| Производитель, модель, серийный номер (UID чипа), версия прошивки | `*IDN?` → `IWP,<модель>,<UID>,<версия>` |
| ID чипа | `SYSTem:UID?` |
| Версия SCPI | `SYSTem:VERSion?` |
| Частота CPU | `SYSTem:CLOCk?` |
| Температура платы (встроенный датчик, ±2…5 °C) и график за 5 минут | `MEASure:TEMPerature?`, раз в секунду |
| Время работы | `SYSTem:UPTime?`, раз в 2 с |
| Свободная куча FreeRTOS (текущая, минимум за всё время) | `SYSTem:HEAP?`, раз в 5 с |

## Вкладка GPIO

Плата Raspberry Pi Pico сверху (USB вверху), у каждой физической ножки: номер GP, к чему пин подключён мультиплексором
(`UART0_TX`, `SPI0_SCK`, `I2C1_SDA`, `PWM3_A`, `SIO`, `PIO0`, `ADC0`…), направление, уровень (закрашенная точка = 1) и подтяжка (↑ ↓).
Цвет — по типу периферии, неиспользуемые пины серые; питание и земля показаны как на плате. GP23, GP24 и GP25 (светодиод) нарисованы внутри платы.
Наведите курсор на пин, чтобы увидеть подробности. Команда: `GPIO:MAP?` (один ответ на 30 пинов), раз в 0,5 с только пока вкладка открыта.
Если прошивка не знает `GPIO:MAP?` (нет `gpio_info`), над платой появится сообщение. Раскладка выводов соответствует Pico / Pico W (40 пинов); для
другой платы поправьте таблицу `kPhys` в `picoboardview.cpp`.

## Подключение

Роль `scpi`: транспорт «последовательный порт» (USB-CDC плата видна как COM/tty), терминатор `LF`.
Скорость порта для USB-CDC значения не имеет.

## Ключи модели

`idn, manufacturer, model, serial, firmware, scpi_version, uid, clock_hz, temp_c, uptime_s, heap_free, heap_min, gpio_map, gpio_error`;
график `temperature` (одна нерегулярная серия, °C).

## Как расширять

* Новые опросы: ещё один `poll(...)` в конструкторе `Rp2040Session`.
* Разовые чтения: `query(...)` в `onStart()`.
* Команды от интерфейса: `model->sendCommand("name", arg)` на странице и `onCommand()` в сессии.
* Разбор ответов без Qt лежит в `rp2040parse.h`, тест: `tools/rp2040parse_test.cpp` (запускается в CI).
